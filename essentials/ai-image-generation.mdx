# AI Image Generation

B-Bot Hub uses one image picker for user avatars, agent images, and company images.

## Where images are available

- **Profile**: Change your user avatar.
- **Agent editor**: Change the image of an existing, saved agent.
- **Company**: Change the active company's image.

<Warning>
  Save a new agent before adding its image. The image picker needs the saved agent's ID, so it is not shown during the initial unsaved setup.
</Warning>

## Choose an image source

Select the current image or initials to open the picker.

### Upload

1. Open **Upload**.
2. Select **Choose file**.
3. Choose an image from your device.
4. Review the preview and select **Save**.

### Generate

1. Open **Generate**.
2. Choose one of the four styles: **Professional**, **Friendly**, **Modern**, or **Creative**.
3. Describe the image in the free-text prompt.
4. Select **Generate**.
5. Review the result and select **Save**.

The Hub may add context such as the agent's profession or a company-logo hint to your prompt.

### URL

1. Open **URL**.
2. Enter a direct image URL.
3. Review the preview and select **Save**.

The Hub fetches the image from the URL and uploads it to the selected profile, agent, or company record. The URL must be reachable and return a usable image.

## If an image cannot be saved

- Confirm that the selected record has already been saved.
- For uploads, choose a supported image file.
- For URLs, check that the address is direct and publicly reachable.
- For generation, revise the prompt and try again.
- Read the error message shown by the Hub before retrying.

Generation model, duration, output details, availability, and any provider charges can vary by environment. The image picker does not promise a specific model, completion time, result quality, or cost.
