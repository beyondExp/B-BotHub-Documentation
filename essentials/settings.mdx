### Provider Keys Management

**Centralized API key management for all AI providers:**

<Steps>
  <Step title="Access Provider Keys">

  </Step>

## Chat Settings

**Per-conversation configuration** - Access via the settings icon in chat interface.

### Model Parameters

<Tabs>
  <Tab title="Temperature">
    **Controls randomness and creativity**
    
    - **Range**: 0.0 to 2.0
    - **Default**: 0.7
    - **Low (0.0-0.3)**: Focused, deterministic
    - **Medium (0.4-0.8)**: Balanced
    - **High (0.9-2.0)**: Creative, varied
    
    **Use cases:**
    - Low: Code generation, data analysis, factual queries
    - Medium: General conversation, customer support
    - High: Creative writing, brainstorming, storytelling
  </Tab>
  
  <Tab title="Max Tokens">
    **Maximum response length**
    
    - **Range**: 100 to model limit
    - **Default**: Varies by model
    - **Consider**: Cost vs completeness
    
    **Guidelines:**
    - Short answers: 100-500 tokens
    - Medium responses: 500-2000 tokens
    - Long-form: 2000+ tokens
    
    <Warning>
      Higher token limits increase costs
    </Warning>
  </Tab>
  
  <Tab title="Top P">
    **Nucleus sampling parameter**
    
    - **Range**: 0.0 to 1.0
    - **Default**: 0.95
    - **Lower**: More focused
    - **Higher**: More diverse
    
    **Tip:** Use either temperature OR top_p, not both at extreme values
  </Tab>
</Tabs>

### Model-Specific Settings

Each model can have custom settings:

```javascript
{
  temperature: 0.7,
  top_p: 0.95,
  max_tokens: 4000,
  frequency_penalty: 0.0,
  presence_penalty: 0.0,
  stop_sequences: ["###"]
}
```

**Provider-specific parameters:**
- **OpenAI**: frequency_penalty, presence_penalty
- **Anthropic**: top_k, stop_sequences
- **Google**: candidate_count, stop_sequences
- **Custom models**: Additional parameters in JSON

## Troubleshooting

<AccordionGroup>
  <Accordion title="Settings Not Saving" icon="floppy-disk">
    **Possible causes:**
    - Network connectivity issues
    - Session expired
    - Invalid values
    - Permission errors
    
    **Solutions:**
    - Refresh page and try again
    - Check all required fields
    - Log out and back in
    - Clear browser cache
  </Accordion>
  
  <Accordion title="API Key Issues" icon="key">
    **If keys not working:**
    1. Verify key is correct
    2. Check provider dashboard
    3. Validate key hasn't expired
    4. Ensure proper permissions
    5. Try re-adding the key
    
    **See also:** [Provider Keys Troubleshooting](/essentials/provider-keys)
  </Accordion>
  
  <Accordion title="Performance Issues" icon="circle-exclamation">
    **If Hub is slow:**
    - Clear browser cache
    - Disable unnecessary apps
    - Reduce active conversations
    - Check network speed
    - Try different browser
    
    **Optimize:**
    - Use lighter models
    - Reduce token limits
    - Clean workspace regularly
    - Limit concurrent tasks
  </Accordion>
</AccordionGroup>
