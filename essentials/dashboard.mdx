# Dashboard

The dashboard is the starting point for your work in B-Bot Hub.

## Quick actions

Use the three quick actions to:

- Start a new chat
- Create an agent
- Open Apps

## Your agents

The **Your agents** card shows up to five agents. Select an agent to open its editor, or follow the **Agents** link to see the full list.

If you have not created an agent yet, the card shows an empty state. Create an agent before configuring features that require a selected agent.

## Recent conversations

The **Recent conversations** card shows up to five recently updated conversations. Each entry opens the conversation in chat.

A **Shared** badge identifies a conversation that other people can access. Select **Conversations** to open the complete list. If there are no conversations, the dashboard shows an empty state.

## Usage and analytics

The analytics section covers the most recent 14 days and can show:

- Total tokens
- Traces and observations
- The most-used model
- Reported cost, when available
- Token usage over time
- Usage share by model

Use **Retry** to refresh this section.

The section has separate states for loading, no recorded usage, a request error, and analytics that are not configured for the current environment. An unavailable analytics section does not prevent you from using the quick actions, agents, or conversations above it.
