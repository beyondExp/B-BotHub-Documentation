## What are DeepAgents?

DeepAgents are AI agents that can:

```
┌─────────────────────────────────────────────────────────────────┐
│                    DEEPAGENT CAPABILITIES                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌─────────────┐   ┌─────────────┐   ┌─────────────┐          │
│   │    Tasks    │   │    Files    │   │    Code     │          │
│   │  Management │   │   System    │   │  Execution  │          │
│   └─────────────┘   └─────────────┘   └─────────────┘          │
│         │                 │                 │                   │
│         ▼                 ▼                 ▼                   │
│   Create todos      Read/write        Run Python,              │
│   Track progress    files             JavaScript,              │
│   Multi-step        Persistent        Shell commands           │
│   workflows         storage                                     │
│                                                                 │
│   ┌─────────────┐   ┌─────────────┐   ┌─────────────┐          │
│   │   Memory    │   │   Search    │   │   Browser   │          │
│   │   System    │   │     Web     │   │ Automation  │          │
│   └─────────────┘   └─────────────┘   └─────────────┘          │
│         │                 │                 │                   │
│         ▼                 ▼                 ▼                   │
│   Remember context  Research topics   Navigate websites         │
│   across sessions   Find information  Extract data              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## Task Management

### Task Statuses

| Status | Icon | Meaning |
|--------|------|---------|
| **Pending** | ⚪ | Not started yet |
| **In Progress** | 🔵 | Currently working |
| **Completed** | 🟢 | Finished successfully |
| **Failed** | 🔴 | Encountered errors |
| **Cancelled** | 🟠 | Manually cancelled |

### Creating Tasks

You can create tasks by:

1. **Asking the Agent**: "Create a task to analyze the sales data"
2. **Natural Language**: "I need you to do X, Y, and Z"
3. **Manual Addition**: Click "Add Task" in the workspace

### Task Hierarchy

DeepAgents supports nested tasks:

```
📋 Main Project
├── 📋 Research Phase
│   ├── ✅ Gather requirements
│   ├── 🔵 Analyze competitors
│   └── ⚪ Summarize findings
├── 📋 Development Phase
│   ├── ⚪ Design architecture
│   └── ⚪ Implement features
└── 📋 Testing Phase
    └── ⚪ Write tests
```

## Human-in-the-Loop (HITL)

### What is HITL?

HITL mode requires human approval before the agent takes actions:

```
┌─────────────────────────────────────────────────────────────────┐
│                         HITL FLOW                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   Agent Plans Action                                            │
│        │                                                        │
│        ▼                                                        │
│   ┌─────────────────────────────────────────┐                  │
│   │  "I want to create 3 files and          │                  │
│   │   execute this Python script.           │                  │
│   │   Should I proceed?"                    │                  │
│   │                                         │                  │
│   │   [Approve]  [Reject]  [Modify]         │                  │
│   └─────────────────────────────────────────┘                  │
│        │                                                        │
│        ▼                                                        │
│   Human Reviews and Decides                                     │
│        │                                                        │
│        ▼                                                        │
│   Agent Executes (if approved)                                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### HITL vs Auto Mode

| Mode | Behavior | Best For |
|------|----------|----------|
| **Auto** | Agent acts immediately | Trusted tasks, speed |
| **HITL** | Asks for approval | Sensitive operations, learning |

## Complex Workflow Example

### Building a Web App with DeepAgents

Let's walk through a complete workflow:

<Steps>
  <Step title="Define the Project">
    ```
    You: Create a simple todo app using React and Tailwind CSS
    ```
    
    Agent creates task list:
    - ⚪ Set up project structure
    - ⚪ Create React components
    - ⚪ Style with Tailwind
    - ⚪ Add functionality
    - ⚪ Test and refine
  </Step>
  
  <Step title="Execute Tasks">
    The agent works through each task, creating files:
    ```
    📁 Created files:
    ├── index.html
    ├── App.jsx
    ├── components/
    │   ├── TodoList.jsx
    │   ├── TodoItem.jsx
    │   └── AddTodo.jsx
    └── styles/
        └── app.css
    ```
  </Step>
  
  <Step title="Test the Result">
    Agent runs the preview server:
    ```
    🚀 Preview available at: https://sandbox-xxx.e2b.dev
    ```
  </Step>
  
  <Step title="Iterate">
    ```
    You: Add dark mode support
    ```
    
    Agent updates the code and shows results
  </Step>
</Steps>

## Advanced Features

### Memory Integration

DeepAgents remember context across sessions:
- Project state is preserved
- Preferences are learned
- Previous decisions inform future actions

### Multi-Agent Collaboration

Combine DeepAgents with team members:
```
TechSupport AI (DeepAgent)
├── ResearchBot (gathers information)
├── CodeHelper (writes and reviews code)
└── DocWriter (creates documentation)
```

### Scheduled Automation

Set up recurring DeepAgent tasks:
- Daily reports
- Weekly summaries
- Automated data processing
