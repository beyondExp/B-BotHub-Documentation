# Bienvenue dans B-Bot Hub

B-Bot Hub est l’application web qui permet de créer des Agents IA, d’échanger avec eux et de gérer les ressources et services qu’ils utilisent.

<Note>
  Les anciens écrans, API et documents peuvent employer le terme **Expert** pour
  désigner le même concept. Dans le Hub actuel, le terme principal de l’interface
  est **Agent**.
</Note>

## Pour commencer

<Steps>
  <Step title="Se connecter et terminer l’intégration">
    Suivez le processus de connexion, puis renseignez le contexte de votre espace
    de travail, choisissez un premier objectif et examinez votre plan de
    démarrage. Si la connexion a commencé depuis une page protégée du Hub, vous
    serez ensuite redirigé vers cette page.
  </Step>
  <Step title="Choisir avec qui travailler">
    Utilisez le sélecteur d’Agent sous le logo B-Bot Hub. Choisissez **B-Bot**
    pour obtenir de l’aide sur la plateforme, ou l’un de vos Agents pour un
    travail qui lui est propre.
  </Step>
  <Step title="Ouvrir le Chat">
    Sélectionnez **Chat** dans la barre latérale, saisissez un message et démarrez
    votre première conversation.
  </Step>
</Steps>

## S’orienter dans le Hub

La barre latérale regroupe les pages par fonction :

- **Plateforme :** Tableau de bord, Chat, Conversations et Tâches
- **Construire :** Agents, Ressources, Entraînement, Workflows, Applications et Canaux
- **Découvrir :** Actualités et visites guidées

Le menu utilisateur en bas de la barre latérale contient Profil, Entreprise, Paramètres, Clés, Facturation, les options de thème et Se déconnecter.

Réduisez la barre latérale lorsque vous avez besoin de plus d’espace de travail.

Certaines pages dépendent de l’Agent sélectionné ou des services configurés pour votre compte. Consultez la [disponibilité des fonctionnalités](/fr/roadmap) pour plus de détails.
