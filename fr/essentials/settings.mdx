# Paramètres

La page Paramètres actuelle regroupe les options d’apparence, de langue et de notifications web push.

![Paramètres d’apparence, de langue et de notifications](/images/documentation/settings-overview.png)

## Thème

Choisissez l’un des thèmes suivants :

- **Clair**
- **Sombre**
- **Système**, qui suit les préférences de votre système d’exploitation

Votre choix s’applique à l’interface du Hub.

## Langue

Choisissez **English**, **Deutsch**, **Français** ou **Italiano**.

<Info>
  Certaines parties du Hub ne sont pas encore localisées et peuvent s’afficher
  en anglais.
</Info>

## Notifications web push

La carte Notifications indique :

- si le navigateur prend en charge les notifications web push ;
- l’autorisation actuelle du navigateur ;
- si le service de notifications est configuré.

Sélectionnez **Activer les notifications** pour demander l’autorisation du navigateur et créer un abonnement. Sélectionnez **Désactiver les notifications** pour supprimer l’abonnement actuel.

Si le navigateur ne prend pas en charge les notifications web push, l’action d’activation est indisponible. Si l’autorisation est refusée ou si le service n’est pas configuré, l’activation peut échouer et le Hub affiche la raison signalée.
