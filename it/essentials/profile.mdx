# Profilo

La pagina Profilo mostra l'identità collegata al tuo account B-Bot Hub.

## Nome ed e-mail

Il nome e l'indirizzo e-mail sono di sola lettura nell'Hub e vengono gestiti dal provider di identità.

Se un valore non è corretto, aggiornalo tramite il provider di identità o contatta l'amministratore responsabile dell'account.

## Immagine del profilo

Seleziona l'avatar attuale per aprire il selettore di immagini. Puoi scegliere tra tre sorgenti:

- **Carica**: seleziona un file immagine dal dispositivo.
- **Genera**: inserisci una descrizione, scegli uno stile e genera un'immagine.
- **URL**: inserisci l'URL diretto di un'immagine.

Controlla l'anteprima, quindi seleziona **Salva** per associare l'immagine al profilo.

Per maggiori dettagli, consulta [Generazione di immagini con l'IA](/it/essentials/ai-image-generation).

## Impostazioni correlate

I controlli per tema, lingua e Web Push si trovano nella pagina [Impostazioni](/it/essentials/settings). Le chiavi provider e API B-Bot vengono gestite separatamente in [Chiavi](/it/essentials/provider-keys).
