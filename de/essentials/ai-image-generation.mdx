# KI-Bilderzeugung

B-Bot Hub verwendet dieselbe Bildauswahl für Benutzeravatare, Agenten- und Unternehmensbilder.

## Verfügbare Stellen

- **Profil:** Benutzeravatar ändern
- **Agenteneditor:** Bild eines gespeicherten Agenten ändern
- **Unternehmen:** Bild des aktiven Unternehmens ändern

<Warning>Speichern Sie einen neuen Agenten, bevor Sie sein Bild hinzufügen. Die Bildauswahl benötigt die Agenten-ID und erscheint daher nicht während der ungespeicherten Ersteinrichtung.</Warning>

## Bildquelle wählen

Wählen Sie Bild oder Initialen, um die Auswahl zu öffnen.

### Hochladen

Öffnen Sie **Hochladen**, wählen Sie **Datei wählen**, wählen Sie ein Bild, prüfen Sie die Vorschau und wählen Sie **Speichern**.

### Generieren

Öffnen Sie **Generieren**, wählen Sie **Professionell**, **Freundlich**, **Modern** oder **Kreativ**, beschreiben Sie das Bild, wählen Sie **Generieren**, prüfen Sie das Ergebnis und speichern Sie. Der Hub kann Beruf des Agenten oder einen Firmenlogo-Hinweis zum Prompt ergänzen.

### URL

Öffnen Sie **URL**, geben Sie eine direkte Bild-URL ein, prüfen Sie die Vorschau und speichern Sie. Die URL muss erreichbar sein und ein verwendbares Bild liefern.

## Wenn ein Bild nicht gespeichert werden kann

- Prüfen Sie, ob der Datensatz gespeichert ist.
- Wählen Sie eine unterstützte Bilddatei.
- Prüfen Sie direkte öffentliche Erreichbarkeit der URL.
- Überarbeiten Sie den Generierungs-Prompt.
- Lesen Sie vor erneutem Versuch die Fehlermeldung.

Modell, Dauer, Ausgabedetails, Verfügbarkeit und Provider-Kosten können je Umgebung variieren. Die Bildauswahl garantiert weder Modell, Dauer, Qualität noch Kosten.
