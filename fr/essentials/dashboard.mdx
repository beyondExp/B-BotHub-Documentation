# Tableau de bord

Le tableau de bord est le point de départ de votre travail dans B-Bot Hub.

## Actions rapides

Les trois actions rapides permettent de :

- démarrer une nouvelle conversation ;
- créer un Agent ;
- ouvrir les Applications.

## Vos Agents

La carte **Vos agents** affiche jusqu’à cinq Agents. Sélectionnez-en un pour ouvrir son éditeur, ou suivez le lien **Agents** pour afficher la liste complète.

Si vous n’avez encore créé aucun Agent, la carte affiche un état vide. Créez-en un avant de configurer les fonctionnalités qui nécessitent un Agent sélectionné.

## Conversations récentes

La carte **Conversations récentes** affiche jusqu’à cinq conversations récemment mises à jour. Chaque entrée ouvre la conversation dans le Chat.

Le badge **Partagé** indique une conversation accessible à d’autres personnes. Sélectionnez **Conversations** pour ouvrir la liste complète. S’il n’existe aucune conversation, le tableau de bord affiche un état vide.

## Utilisation et analyses

La section d’analyse couvre les 14 derniers jours et peut afficher :

- le nombre total de tokens ;
- les traces et observations ;
- le modèle le plus utilisé ;
- le coût indiqué, lorsqu’il est disponible ;
- l’utilisation des tokens dans le temps ;
- la répartition de l’utilisation par modèle.

Utilisez **Réessayer** pour actualiser cette section.

Cette section distingue le chargement, l’absence d’utilisation enregistrée, les erreurs de requête et l’indisponibilité des analyses dans l’environnement actuel. Son indisponibilité n’empêche pas d’utiliser les actions rapides, Agents ou conversations affichés au-dessus.
