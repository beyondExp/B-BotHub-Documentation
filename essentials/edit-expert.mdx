# Edit an Agent

Open **Agents**, find a saved agent, and select **Edit**. The editor opens at `/agents/{agentId}`. Select **Save** after changing Basics or Goals; controls in the other tabs save their own changes when you use them.

## Basics

Set the agent's name, profession, and description. Turn on **Pro mode** to edit its system message, function name, and function description.

The profile-picture control also appears in Basics for saved agents.

### Profile image options and limits

- **Upload:** The file picker accepts images. A square image is recommended.
- **Generate:** Enter a description and choose Professional, Friendly, Modern, or Creative. Generated images use a 1:1 aspect ratio.
- **URL:** Enter a direct image URL. The source must allow the Hub to fetch it.

The image control does not display a file-size limit. Unsupported or oversized uploads may still be rejected.

## Goals

Define a northstar and optional measurable goals. Each goal can include a title, metric, baseline, target, time horizon, and notes.

## Abilities

Manage two kinds of prompt cards:

- **Abilities:** Short capability instructions that can be applied in chat.
- **Example questions:** Suggested prompts shown when a user opens a chat.

Add cards manually or generate a starting card, then edit or remove cards as needed.

## Model

Choose the main conversational model and configure supported input and output modalities. Available models depend on provider configuration. Text input and output remain available without extra modalities.

## Team

Add other agents as team members. Team members are made available as tools during a run. If no other agents exist, this tab has nothing to add.

Give team members distinct roles, then test a request that makes the expected routing clear.

## Verify the result

Before testing, define what a successful response must include and what it must not invent. Return to **Chat**, select the edited agent, and use a repeatable request that exercises the settings you changed. If the result needs improvement, change the smallest relevant setting and rerun the same request.
