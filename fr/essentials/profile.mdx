# Profil

La page Profil affiche l’identité associée à votre compte B-Bot Hub.

## Nom et adresse e-mail

Votre nom et votre adresse e-mail sont en lecture seule dans le Hub. Ils sont gérés par votre fournisseur d’identité.

Si l’une de ces valeurs est incorrecte, mettez-la à jour auprès de votre fournisseur d’identité ou contactez l’administrateur responsable de votre compte.

## Photo de profil

Sélectionnez votre avatar actuel pour ouvrir le sélecteur d’image. Trois sources sont disponibles :

- **Téléverser :** sélectionnez une image sur votre appareil.
- **Générer :** saisissez une description, choisissez un style et générez une image.
- **URL :** saisissez l’URL directe d’une image.

Examinez l’aperçu, puis sélectionnez **Enregistrer** pour associer l’image à votre profil.

Pour en savoir plus sur le sélecteur commun, consultez la [génération d’images par IA](/fr/essentials/ai-image-generation).

## Paramètres associés

Le thème, la langue et les notifications web push se règlent dans les [Paramètres](/fr/essentials/settings). Les clés fournisseurs et clés API B-Bot se gèrent séparément sous [Clés](/fr/essentials/provider-keys).
