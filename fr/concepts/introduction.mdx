# Agents IA et vocabulaire fondamental

Un **Agent IA** est une expérience d’IA configurée pour un rôle défini. Dans l’interface et la documentation, il peut aussi être appelé **Agent**. Sa configuration lui confère une identité reconnaissable, des instructions, des capacités facultatives et un modèle.

Un Agent n’est ni automatiquement exact ni autonome. Ses résultats dépendent de ses instructions, de son modèle, du contexte disponible, des outils connectés et de la qualité de la demande de l’utilisateur.

<Note>
  Certains guides plus anciens ou certaines interfaces d’API peuvent encore employer le terme **Expert** pour désigner un Agent IA.
</Note>

## Vocabulaire du produit

### Capacités

Les capacités sont des instructions de comportement réutilisables. Elles aident les utilisateurs à choisir un mode ou une approche pour une conversation. Gardez chaque capacité ciblée et décrivez clairement le comportement attendu.

### Modèles de prompt

Les modèles de prompt sont des prompts préparés qui aident les utilisateurs à démarrer des tâches courantes. Ils illustrent ce qu’il est possible de demander, sans garantir le résultat.

### Connaissances

Les sources de connaissances fournissent des informations auxquelles un Agent peut se référer. Utilisez-les pour le contenu qui doit être maintenu séparément du prompt système, comme la documentation produit ou les politiques.

### Apps et outils

Les apps et outils connectés peuvent fournir des informations ou permettre des actions qui dépassent les capacités du modèle seul. Leur disponibilité et leurs autorisations dépendent de la configuration de l’Agent et de la session de l’utilisateur.

### Équipe

Lorsque cette fonctionnalité est disponible, un Agent peut intégrer d’autres Agents comme membres de son équipe. Considérez chaque membre comme un spécialiste doté d’une responsabilité claire.

### Canaux de distribution

Les **canaux de distribution** définissent comment une expérience fondée sur un Agent atteint les utilisateurs ou les systèmes. Leur configuration est distincte de l’identité et du comportement fondamentaux de l’Agent.

### DeepAgents

**DeepAgents** est un mode destiné aux travaux en plusieurs étapes qui utilise des tâches et des fichiers d’espace de travail. Des contrôles avec validation humaine peuvent ajouter des points de vérification avant certaines actions.

## Un modèle mental utile

```text
Agent = identité + instructions + modèle + capacités autorisées

Expérience = Agent + paramètres de conversation + canal de distribution
```

Un même Agent peut se comporter différemment lorsque le modèle, les outils activés, le contexte disponible ou le canal changent. Testez l’expérience complète qui sera proposée aux utilisateurs.
