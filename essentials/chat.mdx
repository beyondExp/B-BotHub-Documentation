# Chat

Chat is where you work with an Agent in a conversation thread. Select an Agent in the Hub header before you begin. The selected Agent supplies the available models, abilities, connected apps, memories, and workspace behavior.

![New Chat screen in B-Bot Hub](/images/documentation/chat-start.png)

## Start or resume a conversation

Open **Chat** and send a message to create a thread. Use **New chat** to return to an empty conversation without deleting existing threads.

To continue earlier work, open the conversation history button and select a recent conversation. Choose **All conversations** for the full [Threads page](/essentials/threads). When you open an existing thread, the Hub restores its messages and aligns the Agent selector with that thread.

## Send messages

Enter sends a message. Shift+Enter adds a new line.

- Select the paperclip to attach one or more supported files.
- Select the microphone to record and send a voice message.
- Right-click the microphone to open **Live mode**. A short pause ends your turn while Live mode is listening.
- Stop an active response with **Stop**.

Attachment support and voice behavior depend on the selected model and its configured modalities. Your browser must allow microphone access.

### Queue follow-up messages

You can send another message while the Agent is responding. The Hub adds it to the current thread's queue and sends it automatically after the active response finishes.

In the queue panel, you can edit, reorder, remove, or clear waiting messages. Attachments are saved to the thread workspace when they are submitted or queued.

## Review actions and responses

An Agent may pause before an action and display **Action required**. Review the action and its arguments, then choose **Approve** or **Reject**. In **Settings**, **Auto-approve actions** skips these approval prompts; use it only when you are comfortable with the Agent's configured tools.

Message actions appear when you hover over or focus a message:

- **Copy** copies message text.
- **Edit & rerun** changes one of your messages and continues from that point.
- **Regenerate** asks for another response from the preceding checkpoint.
- Version arrows move between branches created by edits or regenerated responses.
- **Message details** shows technical identifiers, time, checkpoint, and version information.

Editing or regenerating creates an alternative branch. It does not overwrite the other version.

## Share a conversation

Select **Invite** in an open thread to share it with a teammate. Choose a company, teammate, and link expiry, then send the invitation or copy the generated link.

Sharing converts the thread into an invite-only company conversation. Only company conversations can be shared. Accepted invitations open the same shared conversation, and shared threads carry a **Shared** badge.

## Use the right drawer

The icon rail on the right opens five panels. On desktop, resize the open drawer by dragging its edge.

### Settings

Configure the current run:

- model and ability
- temperature and Top-p
- extra instructions
- enabled connected apps
- Web search, Wolfram Alpha, and Deep research
- automatic action approval
- voice autoplay
- step limit

The options shown depend on the selected Agent and model.

### Tasks

Shows the Agent's live to-do list for this thread. Items may be pending, active, or completed. This panel is read-only and appears only when the Agent produces task state.

### Files

Browse files produced during the current run and files available for the thread. Select a file to view text, code, or supported media. You can copy content or a media path. Markdown files can be exported as PDF, with a company logo when one is available.

### Preview

Displays a supported website or presentation artifact. You can start or refresh a preview and open it in a new tab. Ordinary file collections do not have a live preview, and preview availability depends on the workspace output and runtime capacity.

### Memories

Shows the selected Agent's memory layers:

- **Core profile** for structured, stable information
- **Long-term** for durable facts and preferences
- **Conversations** for summaries associated with the current thread

You can add a long-term memory and manage entries shown in the panel. Memory content is Agent- and user-specific; do not assume that every message becomes a memory.

For workspace details, see [DeepAgents Workspace](/essentials/deepagents-workspace).
