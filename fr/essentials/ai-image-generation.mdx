# Génération d’images par IA

B-Bot Hub utilise le même sélecteur d’image pour les avatars utilisateur, les images d’Agent et les images d’entreprise.

## Emplacements des images

- **Profil :** modifiez votre avatar utilisateur.
- **Éditeur d’Agent :** modifiez l’image d’un Agent existant et enregistré.
- **Entreprise :** modifiez l’image de l’entreprise active.

<Warning>
  Enregistrez un nouvel Agent avant d’ajouter son image. Le sélecteur a besoin
  de l’identifiant de l’Agent enregistré et n’apparaît donc pas pendant la
  configuration initiale non enregistrée.
</Warning>

## Choisir une source

Sélectionnez l’image ou les initiales actuelles pour ouvrir le sélecteur.

### Téléverser

1. Ouvrez **Téléverser**.
2. Sélectionnez **Choisir un fichier**.
3. Choisissez une image sur votre appareil.
4. Examinez l’aperçu et sélectionnez **Enregistrer**.

### Générer

1. Ouvrez **Générer**.
2. Choisissez un style : **Professionnel**, **Amical**, **Moderne** ou **Créatif**.
3. Décrivez l’image souhaitée dans le champ libre.
4. Sélectionnez **Générer**.
5. Examinez le résultat et sélectionnez **Enregistrer**.

Le Hub peut ajouter à votre prompt du contexte, comme la profession de l’Agent ou une indication relative au logo de l’entreprise.

### URL

1. Ouvrez **URL**.
2. Saisissez l’URL directe d’une image.
3. Examinez l’aperçu et sélectionnez **Enregistrer**.

Le Hub récupère l’image depuis l’URL et la téléverse vers le profil, l’Agent ou l’entreprise sélectionné. L’URL doit être accessible et renvoyer une image exploitable.

## Si l’image ne peut pas être enregistrée

- Vérifiez que l’élément sélectionné a déjà été enregistré.
- Pour un téléversement, choisissez un format d’image pris en charge.
- Pour une URL, vérifiez qu’elle est directe et publiquement accessible.
- Pour une génération, modifiez le prompt et réessayez.
- Lisez le message d’erreur affiché par le Hub avant de recommencer.

Le modèle de génération, la durée, les caractéristiques du résultat, la disponibilité et les éventuels frais du fournisseur peuvent varier selon l’environnement. Le sélecteur ne garantit aucun modèle, délai, niveau de qualité ou coût précis.
