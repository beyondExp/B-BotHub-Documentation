## MCP Marketplace

### What is MCP?

**Model Context Protocol (MCP)** is a standard for connecting AI models to external tools:

```
┌─────────────────────────────────────────────────────────────────┐
│                    MCP ARCHITECTURE                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   B-Bot Expert ──► MCP Client ──► MCP Server ──► Tool/Service  │
│                                                                 │
│   Examples:                                                     │
│   • Expert ──► MCP ──► GitHub API ──► Repository actions       │
│   • Expert ──► MCP ──► Database ──► Query data                 │
│   • Expert ──► MCP ──► File System ──► File operations         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## Building Custom Integrations

### OpenAPI/Swagger Integration

<Steps>

    Get the API's OpenAPI/Swagger JSON file
  </Step>
  <Step title="Import in B-Bot">
    Go to Apps → Custom → Import OpenAPI
  </Step>
  <Step title="Configure Auth">
    Set up authentication method
  </Step>
  <Step title="Select Endpoints">
    Choose which endpoints to expose
  </Step>
</Steps>

### Custom Tool Example

Create a custom tool for your internal API:

```yaml
name: "Inventory Checker"
description: "Check product inventory levels"
auth_type: "api_key"
base_url: "https://api.yourcompany.com"
endpoints:
  - name: "check_stock"
    method: "GET"
    path: "/inventory/{product_id}"
    parameters:
      - name: "product_id"
        type: "string"
        required: true
```

## Troubleshooting Integrations

<AccordionGroup>
  <Accordion title="Authentication Errors">
    **Common causes:**
    - Expired API key or token
    - Incorrect credentials
    - Missing permissions/scopes
    
    **Solution:** Regenerate credentials and reconfigure
  </Accordion>
  
  <Accordion title="Rate Limiting">
    **Common causes:**
    - Too many requests
    - API quotas exceeded
    
    **Solution:** Check API limits, add delays, or upgrade plan
  </Accordion>
  
  <Accordion title="Tool Not Responding">
    **Common causes:**
    - Network issues
    - API service down
    - Incorrect endpoint URL
    
    **Solution:** Verify URL, check service status, test manually
  </Accordion>
</AccordionGroup>
