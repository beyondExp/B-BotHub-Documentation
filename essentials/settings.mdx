# Settings

The current Settings page contains appearance, language, and web push controls.

![Appearance, language, and notification settings](/images/documentation/settings-overview.png)

## Theme

Choose one of these themes:

- **Light**
- **Dark**
- **System**, which follows your operating system preference

The selection applies to the Hub interface.

## Language

Choose **English**, **Deutsch**, **Français**, or **Italiano**.

<Info>
  Some parts of the current Hub are not localized yet and may fall back to English.
</Info>

## Web push notifications

The notifications card reports:

- Whether the browser supports web push
- The browser's current notification permission
- Whether the notification service is configured

Select **Enable notifications** to request browser permission and create a subscription. Select **Disable notifications** to remove the current subscription.

If the browser does not support web push, the enable action is unavailable. If permission is denied or the notification service is not configured, enabling notifications may fail and the Hub displays the reported reason.
