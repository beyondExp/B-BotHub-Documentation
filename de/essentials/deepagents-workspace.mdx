# DeepAgents Workspace

DeepAgents können mehrstufige Arbeit in einem Unterhaltungs-Workspace organisieren. Verfolgen Sie diese Arbeit über **Aufgaben**, **Dateien**, **Vorschau** und **Erinnerungen** in der rechten Chat-Seitenleiste.

Es gibt keinen separaten Deep-Mode-Schalter. Workspace-Inhalte erscheinen, wenn der ausgewählte Agent und seine Tools sie erzeugen.

## Aufgaben

Das Panel **Aufgaben** zeigt den vom Agenten gemeldeten Live-Aufgabenstatus und unterscheidet ausstehende, aktive und abgeschlossene Einträge. Die Liste ist schreibgeschützt. Steuern Sie die Arbeit mit Nachrichten sowie durch Genehmigen oder Ablehnen angeforderter Aktionen. Geplante Automatisierungen verwalten Sie separat auf der [Aufgaben-Seite](/de/essentials/tasks).

## Dateien

Das Panel **Dateien** kombiniert Dateien des aktuellen Laufs mit Dateien des offenen Threads.

- Ordner im Dateibaum durchsuchen
- Text und Code im integrierten Viewer öffnen
- unterstützte Bilder, Audio- und andere Medien anzeigen
- Dateiinhalt oder Medienpfad kopieren
- Markdown als PDF exportieren, optional mit Firmenlogo

Auf dem Desktop öffnet sich die erste verfügbare Datei automatisch. Auf kleineren Bildschirmen wählen Sie eine Datei und kehren über Zurück zum Baum zurück.

Die Dateien gehören zum Unterhaltungs-Workspace. Ihre spätere Verfügbarkeit hängt von Thread und Workspace-Diensten ab. Kopieren oder exportieren Sie wichtige Ergebnisse, statt den Workspace als garantierten Langzeitspeicher zu betrachten.

## Vorschau

Das Panel **Vorschau** unterstützt erzeugte Artefakte: Website-Workspaces können eine Live-Vorschau starten oder reaktivieren, Präsentationen ihre Einstiegsdatei direkt darstellen und gewöhnliche Dateisammlungen melden, dass keine Live-Vorschau verfügbar ist.

Sie können die Vorschau aktualisieren oder ihre URL in einem anderen Tab öffnen. Der Start kann dauern, nach Inaktivität neu erfolgen oder bei begrenzter Laufzeitkapazität nicht verfügbar sein. Nicht beliebiger Code und nicht jeder Dateityp kann ausgeführt werden.

## Erinnerungen

Das Panel **Erinnerungen** gruppiert Informationen für Agent und Benutzer:

- **Kernprofil** enthält strukturierte Profilinformationen.
- **Langzeit** enthält dauerhafte Fakten und Präferenzen.
- **Unterhaltungen** enthält Zusammenfassungen je Thread; im Chat ist diese Ebene auf den offenen Thread gefiltert.

Sie können Langzeiterinnerungen hinzufügen und Einträge verwalten. Eine Nachricht, Datei oder Aufgabe wird nur dann dauerhaft gespeichert, wenn das Speicherverhalten des Agenten dies vorsieht.

## Genehmigungen und Kontrolle

Erfordert ein Tool menschliche Prüfung, zeigt Chat **Aktion erforderlich** mit **Genehmigen** und **Ablehnen**. **Aktionen automatisch genehmigen** kann diese Abfragen für die aktuelle Laufkonfiguration umgehen. Genehmigungen steuern angeforderte Aktionen; sie aktivieren DeepAgents nicht und garantieren keinen autonomen Abschluss. Lassen Sie die automatische Genehmigung bei externen oder sensiblen Vorgängen aus.

## Zugehörige Workspaces

Geplante Aufgaben besitzen eine eigene Workspace-Seitenleiste mit benutzerdefinierten To-dos und Dateien sowie Dateien des letzten Laufs. Dies unterscheidet sich vom Live-Aufgabenstatus im Chat. Siehe [Aufgaben](/de/essentials/tasks).
