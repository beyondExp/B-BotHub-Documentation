api: "GET /v3/public/distribution-channels"

---

## Overview

This endpoint retrieves all distribution channels that have been configured for public access. Distribution channels control where and how AI agents can be accessed.

**Available Distribution Channel Types:**
- **Chat**: For B-Bot Chat app integration
- **Embed**: For website/app embedding
- **Template**: For sharing as public expert template

## Authentication

This endpoint requires an Admin API Key for access.

<ParamField header="X-API-Key" type="string" required>
  Admin API Key for full access
</ParamField>

## Query Parameters

<ParamField query="limit" type="integer" default="20">
  Maximum number of results to return
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of results to skip (for pagination)
</ParamField>

## Response

Returns an array of distribution channel objects with full metadata.

<ResponseField name="channel_id" type="string">
  Unique identifier for the distribution channel
</ResponseField>

<ResponseField name="name" type="string">
  Name of the distribution channel
</ResponseField>

<ResponseField name="description" type="string">
  Description of the distribution channel
</ResponseField>

<ResponseField name="metadata" type="object">
  Metadata including distribution channel configuration
  
  <Expandable title="metadata">
    <ResponseField name="distributionChannel" type="object">
      Distribution channel configuration
      
      <Expandable title="distributionChannel">
        <ResponseField name="type" type="string">
          Channel type: "Chat", "Embed", or "Template"
        </ResponseField>
        
        <ResponseField name="config" type="object">
          Channel-specific configuration options
        </ResponseField>
        
        <ResponseField name="category" type="string">
          Category (for Template channels)
        </ResponseField>
        
        <ResponseField name="featured" type="boolean">
          Featured status (for Template channels)
        </ResponseField>
        
        <ResponseField name="usage_count" type="integer">
          Number of installations (for Template channels)
        </ResponseField>
      </Expandable>
    </ResponseField>
    
    <ResponseField name="owner" type="string">
      User ID of the distribution channel owner
    </ResponseField>
    
    <ResponseField name="expert_id" type="string">
      ID of the associated expert
    </ResponseField>
    
    <ResponseField name="profileImage" type="string">
      URL to the distribution channel's profile image
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="graph_id" type="string">
  The graph this distribution channel belongs to (typically "bbot")
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of creation
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of last update
</ResponseField>

## Example Request

```bash cURL
curl --location 'https://api.b-bot.space/api/v3/public/distribution-channels?limit=10&offset=0' \
--header 'X-API-Key: your-admin-api-key'
```

```javascript JavaScript
const response = await fetch(
  'https://api.b-bot.space/api/v3/public/distribution-channels?limit=10&offset=0',
  {
    method: 'GET',
    headers: {
      'X-API-Key': 'your-admin-api-key',
      'Content-Type': 'application/json'
    }
  }
);

const distributionChannels = await response.json();
console.log(distributionChannels);
```

```python Python
import requests

url = "https://api.b-bot.space/api/v3/public/distribution-channels"
headers = {
    "X-API-Key": "your-admin-api-key",
    "Content-Type": "application/json"
}
params = {
    "limit": 10,
    "offset": 0
}

response = requests.get(url, headers=headers, params=params)
distribution_channels = response.json()
print(distribution_channels)
```

## Important Notes

<Note>
  **Distribution Channel Requirement**: Only distribution channels with explicit configuration will be returned. Legacy agents without distribution channels are excluded to prevent unintended public exposure.
</Note>

<Warning>
  Users must configure distribution channels through the B-Bot Hub interface before their agents will appear in this endpoint's response.
</Warning>
