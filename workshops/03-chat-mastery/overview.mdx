## The Chat Interface

When you select an expert and navigate to Chat, you'll see a rich interface designed for powerful conversations.

### Welcome Screen

When starting a new chat, you'll see:
- **Expert Greeting**: "Hello I am [Expert Name]" with their profile picture
- **Helper Text**: "How can I help you?"
- **Template Buttons**: Quick-start prompts specific to that expert (e.g., "Example template 1 for Alice Johnson")

<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/chat-interface.png"
  alt="Chat Interface Overview"
/>

### Chat Mode Toggle

At the top of the chat area, you'll see:
- **Chat Mode / Workspace OFF/ON** - Toggle between standard chat and DeepAgents workspace mode

### Message Input Area

The input area at the bottom includes:
- **Text Input**: "Type a message..." placeholder
- **Send Button**: Submit your message
- **Toolbar**: Access to all chat features

### Toolbar Buttons

The toolbar provides quick access to all chat features:

| Button | Feature | Description |
|--------|---------|-------------|
| **menu** | Menu | Toggle toolbar visibility |
| **Choose Abilities** | Abilities | View and activate expert behaviors |
| **Choose previous conversations** | History | Browse and resume past chats |
| **model_training** | Model | Change the AI model being used |
| **Change standard settings** | Settings | Configure temperature, tokens, etc. |
| **Show Memories** | Memories | View and manage expert's memory |
| **Enable/Disable connected Apps** | Apps | Toggle integrations and tools |
| **Show/Hide Tasks** | Tasks | View DeepAgent task panel |
| **Start new chat** | New Chat | Clear and start fresh conversation |
| **Add files to chat** | Upload | Add documents, images, or data |
| **Toggle Voice Input** | Voice | Enable voice recording mode |

## Working with Abilities

Click the **Choose Abilities** button in the toolbar to open the abilities panel:

<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/chat-fourth.png"
  alt="Abilities Window"
/>

### Abilities Panel Structure

| Element | Description |
|---------|-------------|
| **Help button** | Opens contextual help about abilities |
| **"Select an Ability" heading** | Panel title |

### Each Ability Card Shows

- **Ability name** - The title of the ability
- **"Use Ability" button** - Click to activate this behavior

### Activating an Ability

<Steps>
  <Step title="Open Abilities Panel">
    Click the **Choose Abilities** button in the toolbar
  </Step>
  <Step title="Select Ability">
    Click the **Use Ability** button on your desired behavior
  </Step>
  <Step title="Observe Change">
    The expert will now follow that behavioral mode for subsequent messages
  </Step>
</Steps>

<Tip>
  Abilities act as "behavioral modes" that shape how your expert responds. You can switch between them anytime during a conversation!
</Tip>

### 🎯 Exercise: Ability Switching

2. Ask a general question
3. Activate "Troubleshooting Mode" ability
4. Ask the same question again
5. Notice how the response style changes!

### Settings Dialog Structure

The Settings dialog has a clean, organized layout:

| Element | Description |
|---------|-------------|
| **Help button** | Opens contextual help about settings |
| **"Settings" heading** | Dialog title |
| **"Change settings to get better results"** | Helper text |

### Available Settings

<AccordionGroup>
  <Accordion title="Temperature Slider">
    **Interactive slider** that controls randomness in responses:
    - **0.0-0.3**: Very consistent, deterministic
    - **0.4-0.7**: Balanced creativity and consistency
    - **0.8-1.0**: More creative, varied responses
    
    The current value is displayed next to the label (e.g., "Temperature: 0.1")
  </Accordion>
  
  <Accordion title="Top P Slider">
    **Interactive slider** for nucleus sampling:
    - **0.9**: Standard (recommended)
    - Lower values = more focused responses
    
    The current value is displayed next to the label (e.g., "Top P: 0.1")
  </Accordion>
  
  <Accordion title="Additional Instructions">
    A **text field** where you can add extra context or instructions for the current conversation without modifying the expert's base configuration.
    
    Placeholder: "Your text here..."
  </Accordion>
  
  <Accordion title="Private Session Checkbox">
    When enabled:
    - Uses your personal app credentials
    - Conversation not used for training
    - Separate from expert's learning
  </Accordion>
  
  <Accordion title="Streaming Checkbox">
    Controls whether responses stream token-by-token or appear all at once:
    - **Enabled** (default): See responses as they're generated
    - **Disabled**: Wait for complete response before display
  </Accordion>
  
  <Accordion title="Use Todo Workflow (HITL) Checkbox">
    Human-in-the-Loop mode:
    - When enabled, the agent asks for approval before executing actions
    - Useful for controlling autonomous behavior in DeepAgents mode
  </Accordion>
</AccordionGroup>

### Dialog Buttons

| Button | Action |
|--------|--------|
| **Close** | Dismiss dialog without saving changes |
| **Save** | Apply changes to the current session |

## Voice Features 🎤

### Voice Input

B-Bot supports voice input for hands-free interaction:

<Steps>
  <Step title="Enable Voice Mode">
    Click the microphone icon to toggle voice mode
  </Step>
  <Step title="Hold to Record">
    Press and hold the microphone button while speaking
  </Step>
  <Step title="Release to Send">
    Release when done - your speech is transcribed and sent automatically
  </Step>
</Steps>

### Voice Input Tips

<CardGroup cols={2}>
  <Card title="✅ Best Practices" icon="check">
    - Speak clearly at normal pace
    - Use a quality microphone
    - Minimize background noise
    - Pause briefly between sentences
  </Card>
  <Card title="❌ Avoid" icon="xmark">
    - Speaking too fast
    - Background music/TV
    - Very long recordings
    - Mumbling or unclear speech
  </Card>
</CardGroup>

### Audio Output 🔊

| Feature | Description |

## Memory System 🧠

### How Memory Works

Your expert can remember information across conversations:

```
┌─────────────────────────────────────────────────┐
│                  MEMORY SYSTEM                   │
├─────────────────────────────────────────────────┤
│                                                 │
│   User Input ───► Memory Check ───► Response    │
│        │              │              │          │
│        ▼              ▼              ▼          │
│   "Remember       "User prefers    Personalized │
│    I prefer        detailed        response     │
│    detailed        explanations"   with extra   │
│    explanations"                   detail       │
│                                                 │
└─────────────────────────────────────────────────┘
```

## QA Marking for Training

QA marking lets you create training data from real conversations:

<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/chat-thirteenth.png"
  alt="QA Marking"
/>

### How to Mark QA Pairs

<Steps>
  <Step title="Enable QA Mode">
    Click the three dots on a message and select "Start QA Marking"
  </Step>
  <Step title="Select Question">
    Click the user message you want as the question
  </Step>
  <Step title="Select Answer">
    Click the expert response you want as the answer
  </Step>
  <Step title="Confirm">
    Review and save the QA pair for training
  </Step>
</Steps>

<Info>
  QA pairs are used to fine-tune your expert and improve its responses over time!
</Info>

### HITL (Human-in-the-Loop)

When enabled, the agent asks for approval before actions:

**Auto Mode:**
```
Agent: ✓ Creating task...
Agent: ✓ Complete!
```

**HITL Mode:**
```
Agent: ❓ I propose to create 3 tasks. Approve?
User: [Approve] [Reject] [Modify]
```
