# AI-Powered Profile Image Generation

B-Bot Hub includes AI-powered image generation to create professional profile pictures for your experts. Using advanced AI models, you can generate custom avatars that match your expert's personality and role.

## Accessing AI Image Generation

AI image generation is available when:
- **Creating a new expert** (Step 2: Profile Picture)
- **Editing an expert's profile picture**
- **Creating an assistant** (in the configuration wizard)

## Using AI Generation

### Quick Start

<Steps>
  <Step title="Select AI Generate Tab">
    Click on the **AI Generate** tab in the profile picture selector.
  </Step>
  
  <Step title="Choose Expert Type">
    Select from pre-configured templates:
    - AI Expert
    - Marketing Expert
    - Finance Expert
    - Healthcare Expert
    - Legal Expert
    - Technology Expert
    - Education Expert
    - Business Expert
  </Step>
  
  <Step title="Select Style">
    Choose the professional style:
    - **Professional**: Corporate, business attire
    - **Friendly & Approachable**: Warm, welcoming
    - **Modern & Tech**: Contemporary, innovative
    - **Creative**: Artistic, unique
  </Step>
  
  <Step title="Generate">
    Click **Generate Image**. The AI will create your profile picture in 10-30 seconds.
  </Step>
</Steps>

### Advanced Options

<AccordionGroup>
  <Accordion title="Custom Prompts" icon="pen-to-square">
    Want more control? Edit the auto-generated prompt or write your own:
    
    ```
    Professional headshot of a friendly AI assistant expert, 
    modern office background, neutral expression, 
    business casual attire, warm lighting, 
    high quality photography, detailed face
    ```
    
    **Tips for good prompts:**
    - Be specific about appearance and setting
    - Include lighting and quality descriptors
    - Mention attire and expression
    - Keep it professional for business use
  </Accordion>
  
  <Accordion title="Appearance Customization" icon="user-pen">
    Customize the generated appearance:
    - **Gender**: Male, Female, Neutral
    - **Age**: Young Adult, Middle-Aged, Senior
    - **Ethnicity**: Diverse options available
    - **Expression**: Professional, Friendly, Serious, Approachable
  </Accordion>
  
  <Accordion title="Background Options" icon="image-landscape">
    Choose the background style:
    - **Office**: Modern professional workspace
    - **Studio**: Clean, solid color backdrop
    - **Outdoor**: Natural, professional setting
    - **Tech**: Digital, futuristic environment
    - **Custom**: Specify in your prompt
  </Accordion>
</AccordionGroup>

## Image History

<Info>
  The AI Generation tab automatically saves the last **8 generated images** for quick selection.

### Using Image History

1. Previously generated images appear as thumbnails below the generation form
2. Click any thumbnail to select that image
3. History persists across sessions
4. Each expert has its own image history

## Technical Details

### AI Model
B-Bot Hub uses **BFL FLUX Kontext Pro**, a state-of-the-art image generation model that produces:
- Photorealistic portraits
- Consistent facial features
- Professional quality output
- 1024x1024 resolution (1:1 aspect ratio)

### Generation Time
- **Average**: 15-20 seconds
- **Range**: 10-30 seconds depending on server load
- Loading indicator shows progress

### Image Quality
- **Resolution**: 1024x1024 pixels
- **Aspect Ratio**: 1:1 (square)
- **Format**: PNG (converted from API)
- **Quality**: High-definition, suitable for professional use

## Troubleshooting

<AccordionGroup>
  <Accordion title="Generation Failed" icon="exclamation-triangle">
    **Possible causes:**
    - API rate limit reached
    - Prompt contains restricted content
    - Network connectivity issues
    - Service temporarily unavailable
    
    **Solutions:**
    - Wait a few moments and try again
    - Simplify or modify your prompt
    - Check your internet connection
    - Contact support if issue persists
  </Accordion>
  
  <Accordion title="Image Quality Issues" icon="image-slash">
    **If image quality is poor:**
    - Add quality keywords: "high detail", "professional photography", "8k"
    - Specify lighting: "studio lighting", "natural light", "soft lighting"
    - Be more specific about composition
    - Generate multiple images and pick the best
  </Accordion>
  
  <Accordion title="Wrong Appearance" icon="face-frown">
    **If the image doesn't match expectations:**
    - Be more explicit in your prompt
    - Use the appearance customization options
    - Try different style presets
    - Reference specific attributes you want
  </Accordion>
  
  <Accordion title="URL Expires Warning" icon="clock">
    **Important:** Generated image URLs expire after 10 minutes!
    
    B-Bot Hub automatically downloads and converts images to prevent loss. If you see this warning:
    - The image is already saved in your browser
    - Save/create the expert to persist the image
    - Don't leave the page without saving
  </Accordion>
</AccordionGroup>
