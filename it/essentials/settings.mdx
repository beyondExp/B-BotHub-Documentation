# Impostazioni

La pagina Impostazioni contiene i controlli per aspetto, lingua e Web Push.

![Impostazioni di aspetto, lingua e notifiche](/images/documentation/settings-overview.png)

## Tema

Scegli uno dei seguenti temi:

- **Chiaro**
- **Scuro**
- **Sistema**, che segue la preferenza del sistema operativo

La selezione si applica all'interfaccia dell'Hub.

## Lingua

Scegli **English**, **Deutsch**, **Français** o **Italiano**.

<Info>
  Alcune parti dell'Hub non sono ancora localizzate e possono essere mostrate in inglese.
</Info>

## Notifiche Web Push

La scheda Notifiche indica:

- se il browser supporta Web Push
- l'autorizzazione corrente del browser per le notifiche
- se il servizio di notifica è configurato

Seleziona **Abilita notifiche** per richiedere l'autorizzazione del browser e creare un'iscrizione. Seleziona **Disabilita notifiche** per rimuovere quella corrente.

Se il browser non supporta Web Push, l'azione di attivazione non è disponibile. Se l'autorizzazione viene negata o il servizio non è configurato, l'attivazione può non riuscire e l'Hub ne mostra il motivo.
